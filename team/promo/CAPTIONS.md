# BrodieGroove launch captions (Day 0 to Day 7)

Tokens like `{{CALL_LINE}}` are filled from `config.json` into `data/tmp/promo/captions_filled.md` whenever you run
`python -m team.promo.render`. Post from the filled file. If a token is still showing, that config value is empty.
Times are local. Files are under `data/tmp/promo/<day>/`.

Voice rules: short and punchy, light slang, never cringe. One emoji at most per line. Lead with the hook, and put the
CTA in the first 2 lines on X and LinkedIn (they cut off long posts).
